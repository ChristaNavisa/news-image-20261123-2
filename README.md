# THE WORLD TODAY — Monday 23 November 2026

One page of world news: 36 dated stories from Monday 23 November 2026,
drawn as a classic broadsheet — big date masthead, six-number stat strip,
region bar, three illustrated leads with bodies, twelve illustrated cards,
a numbered schematic world map, an in-brief list and a date check.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Writes `out/entry.png` (1024×1024, under 1 MiB). Python 3.13, standard
library only — no Pillow, no network, no randomness. Two runs write
identical bytes: the PNG encoder and the 5×7 bitmap font are written
from scratch in `main.py`, and every picture on the page is drawn in code.
